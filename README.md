# LangChain Basic Agent

Учебный проект PEl04 курса Zerocoder — создание базового AI-агента на LangChain с использованием локальной LLM.

## Цель проекта

Создать AI-агента, который самостоятельно определяет необходимость вызова Python-инструмента для выполнения математических вычислений.

## Технологии

- Python 3.12
- LangChain 1.4.4
- LangGraph 1.2.14
- Ollama
- Qwen2.5:3b

## Архитектура

**Пользователь → LangChain Agent → Qwen2.5 → Tool → Результат → Ответ**

Основные компоненты:

- **LLM:** Qwen2.5:3b — анализирует запрос и выбирает действие.
- **System Prompt:** определяет роль математического помощника.
- **Tool:** `multiply(a, b)` — выполняет умножение двух целых чисел.
- **Agent:** `create_agent()` — организует взаимодействие модели с инструментами через LangGraph.

## Установка и запуск

Требуются Python 3.12 и установленная Ollama.

1. Создать виртуальное окружение:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Установить зависимости:

```powershell
python -m pip install langchain langchain-ollama langgraph python-dotenv
```

3. Загрузить модель:

```powershell
ollama pull qwen2.5:3b
```

4. Запустить агента:

```powershell
python main.py
```

## Результаты тестирования

**Тест 1 — математический запрос**

Запрос: «Сколько будет 7 умножить на 9?»

- Агент самостоятельно вызвал `multiply(7, 9)`.
- Python вернул результат `63`.
- Агент сформировал правильный ответ.

**Тест 2 — обычный диалог**

Запрос: «Привет! Как тебя зовут?»

- Агент определил, что инструмент не требуется.
- Ответил самостоятельно, без вызова `multiply`.

## Вывод

Создан работающий локальный AI-агент на LangChain. Эксперимент подтвердил, что LLM может самостоятельно выбирать инструменты в зависимости от запроса пользователя.

Проект работает без платного облачного API.
